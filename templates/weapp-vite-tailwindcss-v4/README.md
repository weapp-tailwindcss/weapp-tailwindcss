# weapp-vite-tailwindcss-v4

`Native WeChat Mini Program + weapp-vite + Tailwind CSS v4` canonical template.

## Quick start

```bash
pnpm install
pnpm dev
pnpm build
```

Tailwind CSS is generated by `weapp-tailwindcss`. Keep the CSS-first
`@import "tailwindcss"` entry and explicit `@source`; do not add
`@tailwindcss/vite` or `@tailwindcss/postcss` to this build.
