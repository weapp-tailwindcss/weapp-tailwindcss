# @weapp-tailwindcss/native-darwin-arm64

> English | [简体中文](./README.zh-CN.md)

Prebuilt Node-API Rust compiler for `darwin-arm64`. Installed automatically as an optional dependency of `weapp-tailwindcss`; no install scripts, compiler, or download step is required.

Requires Node.js `^20.19.0 || >=22.12.0`. The main package supports Tailwind CSS v4 only and owns the public API.
