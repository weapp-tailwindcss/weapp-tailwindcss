# @weapp-tailwindcss/native-win32-x64-msvc

> English | [简体中文](./README.zh-CN.md)

Prebuilt Node-API Rust compiler for `win32-x64-msvc`. Installed automatically as an optional dependency of `weapp-tailwindcss`; no install scripts, compiler, or download step is required.

Requires Node.js `^22.18.0 || >=24.11.0`. The main package supports Tailwind CSS v4 only and owns the public API.
