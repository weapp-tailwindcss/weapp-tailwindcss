# @weapp-tailwindcss/native-win32-arm64-msvc

> English | [简体中文](./README.zh-CN.md)

Prebuilt Node-API Rust compiler for `win32-arm64-msvc`. Installed automatically as an optional dependency of `weapp-tailwindcss`; no install scripts, compiler, or download step is required.

Requires Node.js `^20.19.0 || >=22.12.0`. The main package supports Tailwind CSS v4 only and owns the public API.
