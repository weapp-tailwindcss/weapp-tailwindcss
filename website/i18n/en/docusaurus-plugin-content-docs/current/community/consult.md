# Consulting and customization services

## Some random thoughts

Most of the open source projects in China like mine are generated for love. Except for sporadic rewards from individual friends, no one sponsors them. Of course, the reward money is also very small. The total reward amount is much less than my daily salary.

It is true that my purpose of doing open source is not for money, but I also know that if an open source project wants to be continuously maintained and improved, it cannot be separated from the support of money.

Just like this project has been `2` years. I maintain the code and documents myself, and spend my own money to deploy it on domestic `CDN`. The total contributors plus me total `2` individuals (as of 2024/1/12), and I am the only one doing daily maintenance.

Some friends add me and say that my document writing is not good and I cannot read it. Can you contribute an easy-to-read version yourself? Do you see the big `link` that edits this page below?
