Before integration, the main concern was that mini programs do not recognize Tailwind class names: characters such as `[`, `]`, and `:` are invalid in wxss, making arbitrary values difficult to use. weapp-tailwindcss handles the escaping, so `bg-[#F7F7F6]` and `text-[28rpx]` work directly in wxml.

`rem2rpx` also removes a separate conversion step. Designs use a 750-wide canvas, Tailwind keeps rem values, and the compiler produces rpx. Tailwind v4 CSS-first configuration and JIT scanning of wxml help keep the main package small.

The page SCSS now contains only safe-area handling, WeChat component resets, and a few keyframes; the rest uses utilities. Thank you to the maintainers.
