接入前最大的顾虑是小程序根本不认 Tailwind 的类名：`[`、`]`、`:` 这些字符在 wxss 里非法，任意值基本没法用。weapp-tailwindcss 把这层转义处理干净了，`bg-[#F7F7F6]`、`text-[28rpx]` 在 wxml 里直接写就生效，设计系统落地几乎零摩擦。

`rem2rpx` 又省掉一整套换算：设计稿按 750 出，Tailwind 那边照常写 rem 尺度，编译出来就是 rpx，不用再维护一份对照表。加上 v4 的 CSS-first 配置和按 wxml 扫描的 JIT，主包体积一直压得住。

现在页面 scss 只剩 safe-area、微信组件 reset 和少量 keyframes，其余全是 utility。原生小程序能有这种开发体验，基本是靠这个库撑起来的。感谢维护。
